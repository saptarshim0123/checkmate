# CheckMate - AI Resume Analyzer

An intelligent resume analysis tool that compares resumes against job descriptions using AI to provide actionable insights and improvements.

## 🚀 Features

- **PDF Resume Parsing** - Extract text from PDF resumes
- **AI-Powered Analysis** - Uses Google Gemini AI for intelligent matching
- **Match Score** - Get a percentage match between resume and JD
- **Gap Analysis** - Identify missing technical and soft skills
- **Resume Improvements** - Get AI-suggested bullet points tailored to the JD

## 🛠️ Tech Stack

**Backend:**
- Python 3.x
- FastAPI
- Google Gemini AI
- PDFPlumber

**Frontend:**
- HTML5
- CSS3
- Bootstrap 5
- Vanilla JavaScript
